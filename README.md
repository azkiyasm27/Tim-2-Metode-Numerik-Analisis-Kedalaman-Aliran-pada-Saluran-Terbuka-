

# Analisis Kedalaman Aliran pada Saluran Terbuka





## 1. PROJECT INFORMATION

- Project Title       : Analisis Kedalaman Aliran pada Saluran Terbuka

- Course            : Metode Numerik (Semester Ganjil 2026/2027)

- Group Number      : Kelompok 2
