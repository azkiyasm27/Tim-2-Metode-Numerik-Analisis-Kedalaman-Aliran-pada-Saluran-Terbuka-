# Tim-2-Metode-Numerik-Analisis-Kedalaman-Aliran-pada-Saluran-Terbuka-
Tugas Besar Metode Numerik (Tim 2) : menentukan kedalaman aliran normal pada saluran tebuka dari persamaan Manning yang nonlinier. Membandingkan konvergensi bisection, Newton-Raphson, dan secant, menyusun kurva debit dan kedalaman dengan interpolasi dan regresi.
